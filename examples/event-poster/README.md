# Event Poster

Use this case for a GPT Image 2 event poster with strong visual direction but blurry or unreliable event copy.

## Expected Assets

- `original.png`: flattened GPT Image 2 poster.
- `problem-crop.png`: close crop showing text blur or fake glyphs.
- `rebuilt-preview.png`: final reconstructed preview.
- `detail-comparison.png`: before/after crop comparison.
- `output/`: SVG/PDF/PNG delivery package.

## Reconstruction Notes

- Confirm event title, date, location, host, and call to action before rebuilding.
- Rebuild title, subtitle, footer, badges, frames, and simple marks as vector text/shapes.
- Preserve scenic, photographic, or painterly background regions as embedded raster.
- Export `publish-4k.png` plus `print.pdf` for review.
