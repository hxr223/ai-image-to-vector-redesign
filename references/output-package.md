# Output Package

Use a stable output package so every reconstruction is easy to review, share, and edit.

## Required Files

- `source.html` or `source.svg`: maintainable source used for export.
- `editable.svg`: editable vector source when the reconstruction is SVG-based.
- `publish-3x.png`: practical high-resolution publishing file.
- `print.pdf`: review or print file.
- `qa-report.md`: notes about reconstruction, text confirmation, and checks.

## Optional Files

- `publish-4k.png`: export when the user asks for 4K or when a platform-safe archive is useful.
- `assets/`: embedded raster assets, such as background crops or product renders.
- `export-report.json`: generated by `scripts/export_artwork.js`.
- `detail-comparison.png`: before/after crop comparison for examples.

## Delivery Notes

Always describe what is actually editable:

```text
Text and layout were rebuilt as vector/HTML structure. Background imagery remains embedded raster for fidelity.
```

When exact text was not confirmed:

```text
Some text was visually approximated because final copy was not provided.
```
